# 🚗 Kniha jízd (Mileage Logbook)

Jednoduchá a plně responzivní webová aplikace pro evidenci pracovních a soukromých jízd. Aplikace běží kompletně v prohlížeči a data ukládá bezpečně na vašem zařízení (nevyužívá externí databázi). Je navržena s ohledem na mobily a podporuje PWA.

## ✨ Hlavní funkce
* **Rychlé zadávání:** Tlačítko pro bleskové předvyplnění nejčastější trasy.
* **Historie a úpravy:** Přehledný výpis jízd s možností plné editace každého záznamu.
* **Statistiky:** Filtrování podle měsíců a automatický součet pracovních/soukromých km.
* **Export:** Stažení dat jedním kliknutím do CSV formátu (pro Excel apod.).
* **Tankování:** Možnost vést si k jízdám poznámky o tankování.

## 🛠️ Technologie
* HTML5, CSS3 
* Vanilla JavaScript
* `localStorage` API pro persistenci dat

## 🚀 Spuštění
Aplikace nevyžaduje žádný backend. Stačí složku nahrát na libovolný webhosting (např. GitHub Pages) nebo jednoduše otevřít soubor `index.html` ve vašem webovém prohlížeči.
